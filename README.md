# MidnightRun (Archived / Legacy Project)

> ⚠️ **Note:** The original source code and screenshots for this project are currently unavailable. However, this repository serves as a portfolio record and technical overview of the application built during this collaborative team effort.

## About the Project
**MidnightRun** is a community-driven web application designed to connect local runners and event organizers through real-time event discovery and engagement. Built using a JavaScript stack paired with a relational database backend, the platform streamlines how recreational running events are created, managed, and shared within local communities.

This was developed as a team project with 4 members. While team members handled dedicated frontend, backend, and high-fidelity UI design responsibilities, I served as the team's **Support Developer**—working across the entire stack to review code, debug issues, and assist team members with technical roadblocks to ensure smooth integration across all modules.

---

## Key Features & Functionality

* 🏃 **Event Creation & Management:** Organizers can publish running events with detailed location data, scheduled times, participant capacity limits, and descriptions.
* 🎟️ **RSVP & Capacity Tracking:** Users can discover upcoming runs, view remaining attendee slots, and register in real time.
* 💬 **Interactive Community Hub:** A central feed for runners to post updates, view event details, and coordinate local group runs.
* 🔔 **Real-Time Notifications:** Alerts sent to users when new events are posted or updates are made to registered runs.

---

## Tech Stack

* **Frontend:** React, Vue.js, HTML5, CSS3
* **Backend:** Node.js, Express.js (RESTful APIs)
* **Database:** MySQL
